# WebDAV 云端文件（Android）

入口：主界面底部「列表」里的「WebDAV 云端文件」，或「设置中心 → 云端文件」。

## 使用

1. 点击「连接设置」，填写完整 WebDAV 目录地址、用户名和密码（也可使用服务商提供的应用专用密码）。支持匿名访问。
2. 保存并连接后，点击目录浏览；「上级目录」只返回配置地址范围内的父目录。
3. 点击影音文件可选择「在线播放」或「下载到手机并加入列表」。播放本目录会将当前目录的影音加入列表并开始播放，不包含子目录。
4. 点击 TXT、EPUB、Markdown、HTML、DOCX、JSON 等受支持电子书，下载后加入现有书架；点击「朗读」开始，继续沿用原来的进度、章节和书签。
5. 「下载整个目录」会递归下载支持的影音和电子书，完成后批量导入；同时有影音和书籍时优先开始影音播放，书籍可从电子书架打开。

当前保存一组连接配置，可编辑或删除。账号密码用 Android Keystore AES-GCM 加密，配置文件及下载文件保存在应用私有的 no-backup 目录；不加入应用设置备份，也不随系统备份迁移。卸载应用会删除这些数据。下载文件持续保留，不依赖可自动回收的临时缓存，重新打开应用后仍能离线使用。

优先使用 HTTPS。HTTP 可用于局域网等环境，但账号与文件在网络上以明文传输。不会忽略服务器证书错误，不会将账号密码写入播放链接。标准重定向中的鉴权只在配置的协议、主机、端口与目录范围内发送；目录浏览不会跟随范围外的跳转。文件下载支持服务端返回的签名下载链接或其他 HTTP(S) 地址，跳转到配置范围外时不携带账号密码，且不允许从 HTTPS 降级为 HTTP。

## 限制和清理

- 本期仅 Android 接入 WebDAV，没有百度网盘接入，也没有改动 Windows 免安装网页版。
- 目前支持 HTTP Basic 用户名/密码认证或匿名访问；不支持 Digest、OAuth、网页登录或自签名证书绕过。
- 下载在页面停留期间执行；离开页面或重建页面会取消未完成操作，不提供后台断点续传。目录下载失败或手动取消时，可导入本次已完成的文件。
- 单个电子书下载上限 64 MB；一次递归最多 2000 个文件、2000 个目录，单目录最多 2000 项。大量文件应分目录操作；超长路径总量也需分批导入。
- 电子书架容量扩展为最近 5000 本，云端目录中的书籍会一次性批量写入，避免旧版最近 50 本的限制截断目录导入。
- 已下载文件以账号、完整云端路径的摘要分目录保存，同名文件不会互相覆盖。再次选择同一个文件会重新下载；下载失败不破坏原有完整文件。
- 「删除连接」仅移除本机连接配置，不删除已下载文件，也不自动清理列表中的云端链接。
- 「清理本地下载」删除本应用下载的所有 WebDAV 文件；云端文件不受影响。请先停止相关播放或朗读，清理后可在书架/列表中移除失效条目。
- 在线播放拖动进度依赖 WebDAV 服务器的 HTTP Range 支持；格式兼容范围与现有播放器一致。

## 验证

构建与静态分析：

```powershell
.\gradlew.bat assembleDebug assembleDebugAndroidTest lintDebug --console=plain
```

只在可丢弃模拟器运行集成测试，测试会修改应用设置、测试账号和列表。测试脚本启动本地模拟 WebDAV 服务器，通过 `adb reverse` 连接，不需要真实账号：

```powershell
python tools/test_webdav_device.py --adb C:\路径\到\adb.exe --serial emulator-5580
```

覆盖加密保存/读取/删除、中文目录与文件名、目录 XML 边界过滤、错误密码、私有文件下载、下载中断不覆盖旧文件、取消、电子书导入、鉴权在线播放与 Range 请求、跨目录跳转不转发密码、重开云端页面使用已保存配置。结果写入 `build/webdav-device-results.txt`，界面截图写入 `build/webdav-browser.png`。
